Network setup

Set up your hotspot once

macOS manages the hotspot name, password and WPA security. Configure these once, then Relay handles VPN and Direct sharing.

  1. Connect the modem to the selected Ethernet adapter and disconnect VPNs for initial setup.
  2. Open Internet Sharing. Turn it off before changing adapters, select Ethernet input and Wi-Fi output, set a network name and WPA2/WPA3 password, then turn sharing on.
  3. Return here, refresh detection, then apply network setup. Connect clients to the hotspot.
